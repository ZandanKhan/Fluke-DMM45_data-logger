Fluke 45 Logger R07

Purpose

Fluke 45 Logger R07 is a Windows 11 desktop application for a Fluke 45multimeter connected through its rear RS-232 serial port. It identifies themeter, reads the primary and secondary displays, updates the GUI continuously,and records timestamped measurements in CSV format.

The application uses Python standard Tkinter and ttk. The only external runtimedependency is pySerial 3.5.

R07 changes

R07 adds the requested operating controls:

START LIVE DISPLAY continuously updates both meter displays.

STOP LIVE DISPLAY stops continuous acquisition without disconnecting.

Live interval (s) controls the continuous display update interval.

Acquire Single Reading remains available for one manual reading.

CSV interval (s) independently controls the CSV sampling interval.

Duration is entered in minutes instead of seconds.

A duration of 0 means continuous CSV logging.

CSV output contains local PC time only. The UTC column was removed.

CSV logging continues to update the live primary and secondary displays.

Live display mode and CSV logging are intentionally mutually exclusive. Stoplive display mode before starting CSV logging. This prevents competing serialcommands and provides deterministic timing. During CSV logging, every loggedsample also refreshes the GUI displays.

System requirements

Windows 11, 64-bit

Python 3.13 installed through the standard Python Windows installer

Python Launcher available as py

Python Tcl/Tk and IDLE feature installed

pySerial 3.5, installed automatically

RS-232 null-modem or crossover cable

USB-to-RS-232 adapter when required

Do not use a USB-to-TTL adapter. The Fluke 45 uses RS-232 electrical levels.

Installation

1. Extract the package

Extract the ZIP file into a new folder, for example:

C:\AI\Fluke45 SerialCom\Fluke45_Logger_R07

Do not run the application from inside the ZIP file. Do not copy an older.venv folder into R07.

2. Install

Double-click:

install_fluke45.bat

The installer:

Confirms Python 3.13.

verifies the Tcl/Tk runtime.

Creates a private .venv.

Installs pySerial 3.5.

Verifies imports.

Builds the complete GUI in hidden test mode.

Runs all automated tests.

A successful installation ends with:

Installation and self-tests completed successfully.
Start the application using run_fluke45.bat.

3. Start

Double-click:

run_fluke45.bat

Recommended Fluke 45 serial setup

Interface:       RS-232
Baud rate:       9600
Parity:          None
Stop bits:       1
Echo:            OFF
Print-only rate: 0

Supported baud rates are 300, 600, 1200, 2400, 4800, and 9600.

Continuous live display

Connect and identify the Fluke 45.

Enter the required value in Live interval (s).

Press START LIVE DISPLAY.

The primary and secondary displays update continuously.

Press STOP LIVE DISPLAY to stop acquisition.

The minimum accepted interval is 0.05 seconds. The actual update rate islimited by the selected Fluke 45 measurement mode, serial speed, and responsetime. A starting value of 1 second is recommended.

CSV logging

Stop live display mode when it is active.

Enter a test name.

Select the output folder.

Enter CSV interval (s).

Enter Duration (min).

Use 0 minutes for continuous logging.

Select Slow, Medium, or Fast meter rate.

Press START CSV LOGGING.

Press STOP LOGGING when required.

CSV columns are:

sample_index
local_timestamp
elapsed_s
primary_value
primary_unit
secondary_value
secondary_unit
raw_response

local_timestamp is generated by the Windows computer and includesmillisecond resolution.

Example CSV

sample_index,local_timestamp,elapsed_s,primary_value,primary_unit,secondary_value,secondary_unit,raw_response
1,2026-07-30T20:15:00.125-06:00,0.000,0.567,OHMS,,,"+5.6700E-1 OHMS"

Diagnostics

Run:

diagnose_fluke45.bat

Launcher errors are stored in:

Fluke45_Logger_R07\launcher_error.log

Application logs are stored in:

%LOCALAPPDATA%\Fluke45Logger\logs\fluke45_application.log
